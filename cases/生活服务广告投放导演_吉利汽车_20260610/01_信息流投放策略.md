# 01_信息流投放策略

投放目标：预约试驾 / 私信咨询 / 到店看车 / 经销商门店留资。

目标人群：

- 首购家庭用户：关注空间、价格透明、售后放心。
- 年轻通勤用户：关注颜值、智能座舱、城市通勤体验。
- 换车用户：关注品质升级、空间升级、品牌口碑、门店政策。

## A 线：真人产品讲解型

适合人群：已有购车意向，想快速了解车型亮点的人。

结构：主持人开场 → 外观 B-roll → 内饰/空间 B-roll → 试驾/门店 CTA。

## B 线：短剧转化型

适合人群：被通勤压力、家庭出行需求触发的人。

结构：痛点低谷 → 朋友/家人触发 → 到店看车 → 状态升级 → 预约试驾 CTA。
