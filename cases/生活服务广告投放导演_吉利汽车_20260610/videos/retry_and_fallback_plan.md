# 视频生成重试与降级计划

当前状态：暂停在视频生成前。

## Smoke Test 顺序

1. 先跑 `A1` 主持人开场。
2. A1 成功后跑 A2-A4。
3. 再跑 `B1` 短剧低谷。
4. B1 成功后跑 B2-B5。

## 成功标准

- 竖屏 9:16。
- 不出现车牌、可读 logo、虚构价格、乱码文字。
- A 线像真人产品讲解，B 线像短剧转化。

## 失败处理

- 出现车牌/logo：加强负面词，重跑单元。
- 出现价格：要求“无具体价格，政策以门店实时信息为准”。
- 人物跑偏：加强对应关键帧作为首图参考。
- CLI 失败：保留 stdout/stderr 和命令，不全量重试。

## 降级策略

不使用静态图粗剪冒充视频。即梦未跑通时，只交付视频前制作包。
