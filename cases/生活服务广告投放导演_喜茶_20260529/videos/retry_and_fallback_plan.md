# 视频生成重试与降级计划

当前状态：暂停在视频生成前。

## Smoke Test 顺序

1. 先跑 `A1`：真人产品讲解型主持人开场。
2. 如果 A1 成功，再跑 A2-A4。
3. 再跑 B1：短剧低谷开场。
4. B1 成功后再跑 B2-B5。

## 成功标准

- 竖屏 9:16。
- 没有真实 logo、乱码文字、汽车元素混入。
- 人物稳定，产品是茶饮，不跑偏到其他品类。
- 动作与单元 prompt 一致。

## 失败处理

| 问题 | 处理 |
|---|---|
| 即梦返回额度不足 | 停止，等待充值 |
| 命令静默 EXIT:1 | 保留命令，不全量重试，检查 CLI/session |
| 人物跑偏 | 加强参考图，重跑该单元 |
| 出现汽车元素 | 在 prompt 中加强“不要车、不要车标、不要汽车” |
| 出现乱码文字 | 要求无字幕无文字，字幕交给剪映 |
| 产品不清晰 | 用产品关键帧作为主参考图重跑 |

## 降级策略

- 不用静态图自动粗剪冒充真实视频。
- 如果即梦暂时不可用，只交付视频前制作包。
- 等单元视频生成后，再进入剪映时间线与成果看板更新。
