# 07_口播与字幕文案

主口播：

今天别再随便买奶茶了。如果你在附近，想喝一杯清爽、不踩雷的，先看这一杯。鲜果感、真茶感、入口不厚重，逛街、上班、看电影前都刚好。尤其下午犯困的时候，一口下去，整个人像被刷新。附近有门店的话，打开平台门店页或喜茶 GO，看实时可下单的产品和优惠。今天这杯，不用纠结。

字幕风格：

- 每屏不超过 14 个汉字。
- 关键词加粗或高亮：清爽、不踩雷、鲜果感、真茶感、附近门店。
- 底部安全区，不挡杯身、不挡人脸、不挡价格或 CTA。

CTA 文案：

- 点进附近门店，看今天能喝到哪一杯。
- 打开喜茶 GO / 平台门店页，查看实时可下单产品。
- 活动与价格以门店及平台实时信息为准。
