# 站位图

## A 版：真人产品讲解型

### A1 主持人开场

```text
手机竖屏 9:16

        玻璃门店背景 / 取茶区虚化
 ┌─────────────────────┐
 │                     │
 │       主持人         │
 │      正面半身        │
 │  左手/右手持茶饮杯    │
 │                     │
 │  底部字幕安全区       │
 └─────────────────────┘
```

要点：

- 主持人居中偏上，杯子在胸口高度。
- 背景是现代茶饮店，不出现真实 logo。
- 底部保留字幕区。

### A2 产品 B-roll

```text
杯子 / 冰块 / 葡萄 / 水珠占画面中央
字幕区在底部，不能挡杯身和果肉。
```

### A3 取茶台

```text
店员手部从画面左侧递杯
顾客手从右侧接杯
背景取茶台虚化
```

## B 版：短剧转化型

### B1 低谷开场

```text
主角坐在桌前，屏幕冷光照脸
人物占画面中上部，环境压暗
底部字幕：我才35岁，怎么每天都这么累？
```

### B3 状态跃迁

```text
主角走出门店
人物由画面中部向前
手中茶饮杯自然出现
背景城市/门店暖光
```
